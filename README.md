# Transformer Visual Lab

**Live page: <https://muzammilafroz.github.io/llm-vl/>**

Sixteen interactive labs covering weeks 1–4 (lectures L1–L25) of IIT Madras BSDA5004 *Large Language Models*. Each lab has four parts:

1. **The math:** the formulas, typeset with KaTeX, with every symbol explained.
2. **Try it:** change the matrices, sizes and sliders.
3. **Your numbers, step by step:** the formula redone live with your inputs.
4. **Exam trap:** the mistake examiners look for.

| Lab | Concept |
|---|---|
| 1 | Self-attention by hand: Q, K, V, row vs column softmax, Z |
| 2 | Attention counts and the causal mask |
| 3 | Multi-head attention and its parameter count |
| 4 | BatchNorm vs LayerNorm |
| 5 | Sinusoidal positional encoding |
| 6 | Decoding: greedy, beam, exhaustive |
| 7 | Sampling: top-k, top-p, temperature |
| 8 | Teacher forcing vs inference |
| 9 | Encoder–decoder data flow and parameters |
| 10 | Seq2seq (Bahdanau) attention |
| 11 | Sequence probability from a model's table |
| 12 | Encoder, causal and cross-attention masks |
| 13 | GPT: pre-training to fine-tuning |
| 14 | BERT masked language modelling (15%, 80/10/10) |
| 15 | BERT input, NSP, fine-tuning and QA |
| 16 | BERT vs GPT |

It's a single static page (`index.html`) that loads KaTeX and Google Fonts from public CDNs. There's no build step and no tracking.

This is an unofficial study aid, not affiliated with or endorsed by IIT Madras. Course content belongs to its authors; refs such as `2025T2-Q13` point to past quiz questions by term and number.
